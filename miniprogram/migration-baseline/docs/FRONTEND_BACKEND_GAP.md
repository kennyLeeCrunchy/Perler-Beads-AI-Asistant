# 前端功能与后端接口对应表

更新时间：2026-07-25

状态定义：

- **已接通**：前端调用真实后端接口，并使用真实响应。
- **部分接通**：核心流程可用，但部分参数、保存或导出语义尚未实现。
- **本地真实**：前端功能真实可用，但只保存在浏览器，不需要或尚未使用后端。
- **演示**：有页面或按钮，但仍是固定数据、无事件或禁用状态。

## 建议实施顺序

1. 先修复两个会误导用户的 P0：制作页固定完成逻辑、PNG“显示色号”选项。
2. 接通完整色卡、裁剪旋转、镜像 / 分区 / PDF 导出，补齐“转图—编辑—交付”闭环。
3. 增加作品与制作进度持久化接口。
4. 最后实现参考图图生图、主体类型和更细的 AI 参数。

旧版 CIEDE2000 与边缘感知实验接口已经放入 `demo/legacy_browser`，不属于当前生产 API。
