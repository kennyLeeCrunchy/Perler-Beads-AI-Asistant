# 微信小程序首审版交付清单

本版本只开放“图片转拼豆图纸、轻量编辑、本地作品、制作辅助、导出相册”。AI 生图入口默认不展示，避免在生成式 AI 合规材料未齐备时影响首次审核。

## 提交前必须替换

- 在 `project.config.json` 中填写正式小程序 AppID。
- 配置 `PINDOU_API_BASE_URL` 对应的已备案 HTTPS API 域名，并在微信公众平台加入 request/uploadFile/downloadFile 合法域名。
- 后端部署后验证 `POST /api/pattern/generate` 与 `POST /api/export/png`；不得在前端放置 AppSecret 或服务端密钥。
- 在微信公众平台隐私保护指引中如实声明：选择相册/相机图片、保存图片到相册、网络请求。产品内隐私页文字必须与平台声明一致。
- 使用真实主体名称、客服联系方式、服务类目和备案信息替换产品占位内容。

## 审核体验路径

1. 首页点击“开始制作”。
2. 从相册选择 PNG/JPG/WEBP（不超过 10 MB）。
3. 选择品牌、尺寸、颜色数，提交生成。
4. 在预览页核对网格和色号统计，保存作品或进入编辑。
5. 在作品页重新打开、重命名或删除本地作品。
6. 在制作辅助页按真实颜色完成进度。
7. 导出 PNG 并授权保存到系统相册。

## 真机回归

- iOS 与 Android 各验证一次选择图片、生成、编辑、保存、重新打开、导出。
- 验证首次拒绝相册权限后可通过设置重新授权。
- 验证断网、接口超时、4xx/5xx、重复点击提交时有明确反馈且不会生成重复任务。
- 验证 52×52 及至少一个更大尺寸；大图编辑时不得导致页面无响应。
- 清空本地数据后作品和临时参数均被移除。
- 所有按钮均有真实行为；不展示 AI、登录、支付、分享等尚未完成的入口。

## 当前边界

- 作品当前保存在本机微信存储，换设备不会同步；界面必须如实提示。
- 后端 `runtime` 目前是文件存储，生产环境需挂载持久卷，容器重启不可丢失生成结果。
- 首版没有账号体系、云同步、支付或公开社区。
